Qwen4-Max Ships With a Million-Token Window

By Dekrov Published November 16, 2026 Updated November 16, 2026

Alibaba’s flagship brings native vision, a 2.4-trillion-parameter backbone and a paid API to coding agents.

Start with the plain-English explanation ↓

Overview

Alibaba opened a Token Plan preview on November 11. The production qwen4-max model reached public API availability on November 16. It accepts text, images and video, and returns text or structured data. For coding agents, that makes it possible to put a screenshot, UI source and test output into the same investigation. [2] [3] [4] [1]

Technical Deep Dive

How it works

Alibaba reports a sparse mixture-of-experts backbone with 2.4 trillion parameters, 71 billion active per token and an extra 328 billion for N-gram embeddings. Each token uses a subset of the experts. The active count describes computation and does not specify the memory needed to host the checkpoint. [1]

Official statement

Alibaba describes the architecture and publishes its own tests. Results depend on the agent harness, reasoning effort and task configuration. [1]

How Qwen4 handles longer sequences

The Qwen team describes three Gated DeltaNet layers for each Qwen Sparse Attention layer. DeltaNet layers compress history into fixed-size state. Sparse attention uses an index to select blocks of earlier context. The model also uses four gated residual branches and learned lookups for short sequences of tokens. The context size describes what fits into a request. Finding a relevant detail deep inside that request remains an evaluation question. [1]

Production limits and cost

Model Studio documents a million-token context window, a thinking-mode input limit of 983,616 tokens, and up to 262,144 combined thinking and answer tokens. The non-thinking output ceiling is 131,072. Input and output ceilings are separate bounds within the shared context. Model Studio documents OpenAI Chat Completions, Responses and Anthropic Messages compatibility. [2]

OpenRouter lists qwen/qwen4-max at $1.50 per million uncached input tokens and $4.50 per million output tokens, with cache reads at $0.075 per million. A request with 250,000 uncached input tokens and 30,000 billed output tokens would cost $0.51 at those rates before cache writes or separate tool charges. A long coding session may resend overlapping context, so cache behavior matters. OpenRouter’s launch snapshot showed around 50 tokens per second at its provider median. Individual requests can vary with prompt size, reasoning effort and provider load. [4]

OpenCode, Qoder and weights

In OpenCode, connect OpenRouter through /connect and look for the model under /models. Catalog refresh timing can vary, and OpenCode also documents custom providers. Qwen lists Qoder, QwenWork and QwenStudio as product surfaces. Model Studio uses a separate qwen4-max-preview ID for its time-limited Token Plan preview. The checked launch materials supply no downloadable Max weights or open-weight license. The verified OpenRouter route is paid. [1] [2] [3] [4] [5]

Explained Simply

A coding agent is an app that connects a model to tools such as a file reader and test runner. Qwen4-Max supplies the model. OpenCode or Qoder decides which tools to expose and how much information to send.

Suppose a dashboard clips a button on mobile. An agent can use a screenshot to see the problem, read the relevant component and suggest a fix. Browser and test access depend on the app running the model. The large context window lets that app include more supporting files and logs.

Try one visual bug and one multi-file regression with the same agent and budget you already use. Compare passing tests, patch size, time and the final bill. The paid model and the separate preview have different limits and terms.

Conclusion

The production release gives developers a model worth testing for visual debugging and long repo sessions. Alibaba reports lower token use than Qwen3.8-Max in its terminal evaluation. For a decision about replacing a current model, measure resolved tasks per dollar in the same agent on the same repository. [1] [2]
