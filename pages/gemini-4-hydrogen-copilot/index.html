Gemini 4 Hydrogen in GitHub Copilot: Access, Cost and What the Benchmarks Prove

By DekrovPublished November 14, 2026Updated November 14, 2026

GitHub added Google’s Gemini 4 Hydrogen to Copilot on November 13, 2026. The important change is practical access across Copilot’s IDE, CLI and agent surfaces—not a new Gemini model release. Here is who can select it, what billing means, and what current coding benchmarks do and do not show.

Start with the plain-English explanation ↓

Overview

GitHub’s November 13 changelog lists Gemini 4 Hydrogen as generally available to Copilot Pro, Pro+, Max, Business and Enterprise users. It can be selected from model pickers across Visual Studio Code, Visual Studio, Copilot CLI, GitHub Copilot coding agent, the Copilot app, GitHub.com, mobile, JetBrains, Xcode, Eclipse and the Copilot SDK. Rollout is gradual, so “GA” does not mean every account will see the picker immediately. [1]

This is a platform integration of the Gemini 4 Hydrogen model Google announced on November 12. Google positions Hydrogen as the faster execution member of the Gemini 4 family; the model itself, its 1-million-token context and its API pricing were covered in our earlier model investigation. This page focuses on what changes inside Copilot and where the documentation still leaves uncertainty. [2]

Technical Deep Dive

Who gets access and where

Copilot Pro, Pro+, Max, Business and Enterprise are explicitly listed. GitHub says the model picker includes ten named surfaces, from editors through CLI and coding agent. The announcement calls the release generally available but also says rollout is gradual; enterprise and business administrators can manage availability through model policies. Under default model enablement, new models are enabled unless administrators have changed that default or disabled this model. [1]

That administrator note matters: a missing model may be a rollout delay or an organization policy, not a broken IDE. Update the client and extension, check the model policy, and compare the exact Copilot surface where you expect it. GitHub’s current docs say model availability can vary by plan and client. [3]

Usage-based billing: model choice affects the credit budget

GitHub says Hydrogen is billed at provider list pricing under usage-based billing. Copilot measures input, cached and output tokens, converts usage into AI credits, and applies each plan’s included monthly allowance; after that allowance, additional usage can be billed in credits. A long agent session may use many model calls, so the cost is not captured by a single prompt or a model’s advertised per-million-token price alone. [1][4]

GitHub’s current public pricing table did not yet show a Hydrogen row when checked on November 14, even though the launch post points users to that table. Therefore this article does not assign Hydrogen a Copilot multiplier or assert an exact Copilot cost. Google’s separate Gemini API rates are not a substitute for the Copilot billing rate. Check the live Copilot billing page and your organization’s usage budget before adopting it broadly. [4]

Copilot surfaces are not all the same

GitHub’s Hydrogen announcement names Copilot coding agent, but its current cloud-agent model-selection guide does not list Hydrogen among the selectable models. The supported-model reference separately lists Hydrogen as GA in Copilot. These pages may represent rollout or documentation timing differences; they do not justify claiming that Hydrogen is already selectable in every cloud-agent entry point. Verify the model picker in the precise client and workflow you use. [1][3][5]

What the coding benchmark says

Cursor’s public CursorBench 4.0 leaderboard evaluates agents on ambiguous, multi-file tasks taken from real Cursor sessions. In its current table, Gemini 4 Hydrogen High scores 54.3%, uses 88,682 tokens, takes 59 steps and is estimated at $5.59 per task. Gemini 4 Carbon High scores 60.4% at $9.22 per task; Gemini 4 Argon High scores 52.9% at $4.57. On this one benchmark and harness, Hydrogen sits between Argon and Carbon on score and cost. [6]

Data handling and model limits

GitHub’s model-hosting page says Gemini models used by Copilot are hosted on Google Cloud Platform. It states prompts and responses are not used by Google to train models, and that encrypted durable-cache data may be retained for up to 24 hours and is not used for training or fine-tuning. The page’s listed models had not yet been updated to include Hydrogen at the time checked, so this is the published Gemini hosting policy, not a Hydrogen-specific confirmation beyond the Copilot rollout itself. [7]

Google’s model card describes Hydrogen as adapted from Gemini 4 Carbon, with closed weights and a combined input/output context window up to one million tokens. It warns of hallucinations, occasional slowness or timeouts, higher token use at higher thinking levels, and a March 2026 knowledge cutoff. These are Google’s disclosures, not independent tests of Hydrogen inside Copilot. [2]

Community Reactions

There is not yet a meaningful body of developer feedback specific to Hydrogen inside GitHub Copilot. Launch-day Reddit comments about the Gemini app mention intermittent visibility during rollout and excitement about trying the model, but they concern Google’s consumer surface, not Copilot. We treat those posts as anecdotal and do not use them to infer Copilot reliability or quality. [8]

The most useful early developer signal is therefore product documentation and benchmark transparency, not a pile of impressions. Copilot users should record plan, client, model picker state, thinking effort where available, credits consumed, task outcome and diff quality so that later comparisons are reproducible.

Explained Simply

What changed?

Hydrogen is a new Google model. The specific news here is that GitHub added it to many parts of Copilot, so paid Copilot users can choose it in supported apps, IDEs and command-line tools.

What might it cost?

Copilot charges usage in AI credits. The amount depends on how many tokens the model and coding agent use. The public Copilot pricing page had not yet published Hydrogen’s exact model row when we checked, so don’t copy Google’s API rate and assume Copilot bills the same way.

What should I do?

Update your Copilot client, check whether your plan and organization policy allow the model, and watch the AI-credits panel on a real task. Compare it with another model on the same bug or feature before deciding it is faster or cheaper for your own projects.

Conclusion

Hydrogen’s Copilot rollout is a meaningful new option for everyday coding, especially where teams want a fast execution-oriented model across several Copilot clients. The evidence supports availability and a promising CursorBench result; it does not prove a universal performance advantage or a precise Copilot cost. Test it in your actual workflow, verify which surface can select it, and monitor AI-credit use until GitHub’s pricing and cloud-agent documentation fully align with the release notice.
