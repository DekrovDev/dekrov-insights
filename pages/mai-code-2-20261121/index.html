MAI Code 2 and Flash: Microsoft’s Coding Models, Benchmarks and Pricing

By Dekrov Published Nov 21, 2026 Updated Nov 21, 2026

MAI Code 2 targets complex repo-level work; Flash targets routine, high-volume coding. Microsoft’s evaluations suggest aggressive price-performance, but the company says its models are not yet tuned for harder research or very long-horizon agent tasks.

Start with the plain-English explanation ↓

Overview

Microsoft introduced MAI Code 2 and MAI Code 2 Flash on November 17, 2026. The larger model is positioned for deep debugging, multi-file implementation and repository-wide reasoning; Flash is for explanations, targeted edits, routine fixes and rapid iteration. Both are available in GitHub Copilot under usage-based billing. The notable tradeoff is not just model size: Microsoft frames Code 2 as an affordable general coding agent and Flash as a low-cost workhorse, while explicitly saying neither is yet tuned for harder scientific problems or very long-horizon agent work. [1][3] [1]

Technical Deep Dive

How it works

Microsoft’s model cards describe a decoder-only transformer with sparse Mixture-of-Experts layers and an integrated vision encoder. The cards give broad size ranges rather than exact parameter counts: 50–100B total with 80B active for Code 2, and 5–15B total with 12B active for Flash. Both accept text and images and list a context window of about 1.05 million tokens. These are closed models delivered through products; their listed terms depend on deployment, rather than a downloadable open-weight license. The model card describes the model family and intended use, but does not expose enough implementation detail to independently reproduce training or inference behavior. [2]

Official statement

Microsoft’s release post and model cards provide the product’s claims and model specifications. Their benchmark comparisons combine Microsoft-run evaluations with selected external scores and pricing assumptions; they do not establish that every team will see the same quality or cost. The comparison set is limited to named tasks and configurations, and no independent rerun of the full comparison was found in this source check. [1]

What Microsoft’s benchmark comparison actually says

Microsoft reports that Code 2 reaches 98% of GPT-6.1 Sol’s average performance at 40% of its cost, and 96% of Claude Opus 5.5’s performance at 5% of the cost. The four-task average includes DeepSWE 1.1, Terminal Bench 2.1, SWE-Atlas and FrontierCode 1.1. Microsoft says the first three were run on its internal MSBench platform with GitHub Copilot CLI and no subagents; FrontierCode results and costs came from Artificial Analysis. The Code 2 cost comparison uses a 50% promotional price. Treat the result as a vendor-reported evaluation, not an independent controlled comparison. [1]

For Flash, Microsoft reports performance comparable to GPT-6 Luna and Claude Haiku 5.5 at 65% and 20% of their costs across three routine-coding benchmarks. Again, the page notes max reasoning effort and the same internal harness for DeepSWE, Terminal Bench and SWE-Atlas, with promotional pricing in the cost calculation. These claims are workload-specific; Microsoft itself says the models are not yet tuned for very hard research and very long-horizon agent work. [1]

OpenCode was announced as “coming soon”

Microsoft said it planned distribution through OpenRouter, Vercel, Hermes, OpenCode and Kilo, but described those routes as forthcoming. At release, Code 2 was available through Copilot, while Flash had limited-access preview in Microsoft Foundry. The model card lists product and service terms, not an open-source license. Do not treat a future provider integration as open weights or free local inference. [1][2]

Explained Simply

Microsoft released two AI models that can write and change code. Code 2 is intended for bigger jobs across multiple files; Code 2 Flash is intended for smaller, frequent changes. They are offered inside GitHub Copilot, not as open files that anyone can download and run on a personal computer.

Think of them as two contractors: one for complicated renovation work, the other for quick repairs. The second costs much less per job, but you would not send it to rebuild an entire house. A developer can pick a model based on task size, but the final bill still depends on tokens used, cached input and whether promotional pricing applies.

At the time of this check, Code 2 is available on Copilot Pro, Pro+, Max, Business and Enterprise; Flash also appears on Copilot Free and Student. The GitHub documentation lists promotional prices through May 17, 2027, followed by higher standard rates. Microsoft says access through Foundry is limited preview for Flash and describes OpenCode and other hosts as coming soon; it does not say the weights are open. Teams should check the current model policy and billing page, then test the model on representative tasks before routing production work to it.

Conclusion

The useful promise is task routing: Code 2 for multi-file and repository-level engineering, Flash for repetitive edits where token cost matters. Microsoft reports competitive scores and large cost gaps, but those are vendor comparisons, with mixed evaluation provenance and promotional prices. The model cards also show these are product-governed closed models, not locally downloadable open weights. Try them on the same issue set and harness as your current model, measure review acceptance and full task cost, and revisit the comparison when the promotion or rollout changes.
