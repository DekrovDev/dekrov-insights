Kimi K3.1 Pro:
Frontier-Level, but Not Yet Open

01 / Independent intelligence result

Artificial Analysis' Intelligence Index (version shown Oct 24): K3.1 Pro scores 55 and ranks #4 among 215 listed models. This is a composite score, not a percentage and not proof it wins every coding task.

Kimi K3.1 Pro · AA Intelligence Index

Kimi55 pts

Single-model score shown on a 0–100 plot; no invented comparison bars. AA also measured ~73.5 output tokens/sec for the standard API model, calling it slower and more verbose than average. Different providers or versions may vary.

Independent result: Artificial Analysis. Separately, Vals AI currently lists 62.52% ± 1.14 on the Vals Index (#8/27), and 63.64% ± 1.75 on its Terminal-Bench 4.0 evaluation (#3/55). Different indices cannot be compared as if they were the same test.

Open weights and the security trade-off

Moonshot says it intends to publish the full model weights by November 4, 2026. At the time of this report, the company has not shipped those weights or named the license. Until then, you can use the hosted tools and API, but should not assume you can self-host K3.1 Pro.

The company also says it deliberately filtered cyber-related material during training to reduce misuse risk. On its internal vulnerability-exploitation benchmark, the unfiltered checkpoint reached 90.5% while the released K3.1 Pro configuration scored 81.0%. Reuters independently reported the company's decision, but not an independent replication of those scores.

Where developers can try it

Use Kimi, Kimi Work, Kimi Code (switch with /model), or the Moonshot API with IDs kimi-k3.1-pro and kimi-k3.1-pro-highspeed. Windows users can use the Kimi Work desktop app version 3.1.0 or later.

What I would actually test

Try the same multi-file coding issue, browser/tool workflow and small CAD-to-geometry task on K3.1 Pro and your current agent model. Track completed tasks, tool-call failures, turnaround time, generated tokens and final API bill. Treat website demos and vendor leaderboards as reasons to test — not as results from your own workflow.
