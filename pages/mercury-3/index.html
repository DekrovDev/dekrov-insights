Why diffusion matters

Traditional autoregressive language models produce tokens sequentially. Diffusion language models iteratively refine multiple tokens in parallel. This can reduce generation latency, but speed alone does not guarantee correct code, robust tool use, or faster end-to-end agents.

What is actually available?

Mercury 3 is offered through Inception's API and announced via OpenRouter, Baseten and Vercel. The API is OpenAI-compatible. The model is proprietary: public weights are not available. The 100M-token offer applies to new accounts and is subject to provider terms.

What I'd test next

Run the same real coding-agent tasks through Mercury 3, DeepSeek V4.1 Flash and GLM-5.3 Flash. Record task success, first-token latency, end-to-end completion time, tool-call reliability and total billed tokens. Don't infer any of those results from vendor throughput alone.
