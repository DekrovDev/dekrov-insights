Geo Sleuth Turns Photo Location Guesses Into Evidence

By Dekrov Published November 16, 2026 Updated November 16, 2026

A look at Oldcircle’s MIT-licensed agent skill, the evidence it returns and the limits of its published demos.

Start with the plain-English explanation ↓

Overview

Geo Sleuth is Oldcircle’s open-source photo geolocation skill. Its design gives a general-purpose agent a way to compare competing explanations against external evidence and return supporting artifacts. That makes it an interesting case study for anyone building an agent that must justify its conclusions. [1]

Technical Deep Dive

How it works

The skill separates clue extraction, candidate ranking and final judgment. Python tools calculate and rank candidates. The model interprets the results and decides which checks are worth doing next. The documented output includes a location estimate, a camera bearing, an uncertainty radius and supporting imagery. The radius is a reported estimate whose calibration has not been established by the published examples. [2]

Official statement

Oldcircle reports three worked examples with errors of about 2 metres, within 100 metres and about 3 metres. The first result took roughly 72 minutes. These are individual author-reported cases. The first was the run that informed the skill’s design, so it cannot serve as a blind evaluation of the finished skill. [1]

What runs in the agent

The repository ships a standard skill file and Python scripts rather than a standalone model. The author lists Codex, Claude Code, Cursor, Gemini CLI, OpenCode and Copilot. Those are compatibility claims, and the available tools and approvals still depend on the host. The code carries an MIT license. Model usage and external service access depend on the agent and provider. [1] [3]

What the extra tools buy you

A basic vision prompt can offer a quick hypothesis. Geo Sleuth adds explicit candidate ranking and output artifacts the reader can inspect. The trade-off is setup and dependency on external imagery and mapping coverage. Its diagnostic script describes a local setup check and optional endpoint reachability checks, with no photo upload in the diagnostic itself. The full skill can use external reverse-image services, so review your host’s permissions before passing in any sensitive photo. [2] [4]

Explained Simply

Imagine you are trying to recognize a public trail from a holiday photo. Several mountains look alike at first. A candidate is a place that could explain the scene. Evidence is something you can inspect to see why one candidate fits the visible landscape better.

The skill helps the agent show the work behind its estimate. An evidence image can let a reader spot an obvious mismatch, even when the agent sounds confident. If the map is incomplete or the photo lacks distinctive features, the responsible result may be a broad estimate or no conclusion.

Use photos you own or have permission to analyze, such as public landmark or trail images. Before using a personal photo, check which services the host agent and skill are allowed to contact. A local setup check cannot guarantee that the complete workflow keeps every image on your device.

Conclusion

Geo Sleuth’s contribution is a reviewable chain from observations to a ranked answer. Its code and selected cases are public. A useful benchmark would run unseen public-location photos with known ground truth, record failures and compare errors, time and tool calls against a vision-only agent.
