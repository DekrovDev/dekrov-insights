GPT-6.1 Terra:
Fast Computer Use, Lower Cost

Released October 26, 2026, OpenAI's GPT-6.1 Terra focuses on visual reasoning, interacting with software, and natural writing. Its strongest argument is not that it replaces the flagship Astra: it brings capable agent workflows to a much lower price point. Here are the verified specifications, benchmark claims, prices, and practical trade-offs.

At a glance

Terra is an efficiency-focused reasoning model, not OpenAI's most capable general-purpose model. OpenAI positions it for tasks such as interpreting technical drawings, navigating application screens, reading invoices, completing forms, drafting communications, and scoped software fixes. Its standard API token rates are 50% below GPT-5.6 Terra and GPT-6.1 Sol. The company also says the same plan allowance covers more tasks with Terra than with Sol or Astra.

Editorial note: The benchmark numbers below are published by OpenAI unless otherwise identified. These are model or agent evaluations under particular settings, not guarantees of success, independent replication, or measured performance for every application.

Real task cost: lower prices do not always win

On Agents' Last Exam v1 at max effort, OpenAI's chart estimates $1.01 per task for Terra, $2.00 for Sol and $7.24 for Astra. OpenAI also says Terra completes the evaluated professional tasks more than three times faster than Sol and Astra. This is measured task completion time, not a universal tokens-per-second advantage.

Yet on OSWorld 2.1 at max effort, the displayed estimated cost is about $1.19 per task for Terra versus $1.15 for Sol. And on Terminal-Bench 4.0, Sol at medium effort reaches 52.7% at about $1.02 per task, beating Terra at max effort (50.3%, approximately $1.84 per task). Both cost examples are reported in the published launch-chart transcription. Token consumption, reasoning depth, tool use, and retries can outweigh list-price savings.

How to interpret this: Terra is a strong starting point for frequent screen-based, visual or bounded office tasks. Sol remains attractive for complex coding when you care about successful completion per dollar. Astra is the highest-capability option for the hardest problems. Benchmark wins are specific to the tests and settings shown here.

04 / Coding: more than twice the earlier published score

On Terminal-Bench 4.0, an agent coding test performed from the command line, the new model solves 50.3% of tasks at maximum reasoning effort. OpenAI reports 21.5% for GPT-5.6 Terra, a 28.8 percentage-point increase. That is a benchmark improvement, not a claim that all software engineering becomes twice as reliable.

GPT-6.1 Terra · max50.3%
GPT-5.6 Terra · published21.5%

OpenAI nevertheless recommends GPT-6.1 Sol or GPT-6 Astra for the hardest coding tasks. On Terminal-Bench-Science 0.1, which uses code for scientific work, Terra at max reasoning reportedly beats Sol while costing less, and finishes within five points of Claude Opus 5.5 at under one-fifth the estimated cost. These are different benchmarks: the science result does not establish that Terra is the stronger model across general coding.

06 / Factual accuracy and safety

On OpenAI's internal, error-inducing question set, factual error rates improved substantially. The measurement matters, but it should not be presented as an externally validated hallucination rate for all user questions.

GPT-5.6 Terra · low53.6%
GPT-6.1 Terra · low16.7%

At max reasoning effort, OpenAI says Terra's error rate on that same evaluation falls to 4.3%, 18 percentage points below its predecessor. The company also reports better adherence to task scope and resistance to prompt-injection attempts in its evaluations.

Security classification: OpenAI says GPT-6.1 Terra meets the Critical cybersecurity capability threshold under its Preparedness Framework and uses protections developed for GPT-6 Astra. This classification describes assessed model capabilities and safeguards; it is not a statement that ordinary users are under active attack, nor does it eliminate the need for agent permission controls.

07 / Availability and how to use it

  • ChatGPT Work and Codex: Released for Plus, Pro, Enterprise and Edu users, according to OpenAI's October 26 announcement. Available models and allowances may differ by product.
  • OpenAI API: Select gpt-6.1-terra. The published model page lists no free-tier support for this model.
  • Tool-based agents: Use the Responses API for tool calling. Supply the appropriate tools and authorization; model access alone does not grant computer permissions.
  • Reasoning setting: Start with medium, the default. Use none or low for simpler throughput-focused workloads, and test higher efforts when reliability matters enough to justify added reasoning costs.
MINIMAL PYTHON / RESPONSES API
from openai import OpenAI

client = OpenAI()
response = client.responses.create(
    model="gpt-6.1-terra",
    reasoning={"effort": "medium"},
    input="Summarize the trade-offs of this design."
)
print(response.output_text)

The example assumes a configured OpenAI API key and an installed compatible SDK. It makes a text request only; to operate software or analyze images, add the relevant input and permitted tool configuration.

08 / Should developers choose Terra, Sol or Astra?

Use caseRecommended starting point
High-volume document handling, screen automation, visual extractionTerra
Routine code fixes, short-form writing, bounded agent workflowsTerra, then evaluate errors
Complex engineering tasks and deeper multi-step reasoningSol
Most demanding reasoning and coding workAstra

Editorial assessment: Terra is compelling when you can verify outputs automatically and run many repeatable tasks. The lower token cost can matter more than small differences in frontier scores. For long, ambiguous or high-stakes workflows, evaluate Sol and Astra on your own examples before optimizing for price. Benchmarks are useful signals, but not substitutes for testing your target workflow.
