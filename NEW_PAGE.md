# Как добавить новую страницу

Сайт остаётся статическим: нет базы данных, сборки и сервера. Новая статья — это папка с `index.html`, одна запись в `pages.json` и одна строка в списке на главной.

Коротко: скопируй `_template/index.html` в `<slug>/index.html`, заполни пустой каркас, добавь объект в `pages.json` и строку в `index.html`.

## Что за что отвечает

- `_template/index.html` — пустой каркас страницы: шапка, меню, футер и пустой `.article-body`. Внутри нет текста, примеров и плейсхолдеров: содержание придумывает и пишет ChatGPT по образцу `beam-vs-deepseek/index.html`.
- `pages.json` — единый список страниц для левого меню. `site.js` читает его и строит навигацию на каждой странице. Поэтому при добавлении статьи **не нужно** править меню в старых статьях.
- `site.js` — маленький скрипт, который собирает меню из `pages.json`. Список запрашивается с `cache: "no-store"`, поэтому новая запись появляется без жёсткого обновления страницы.
- `index.html` — главная. Список `Pages` здесь статический: его видят поисковики и пользователи без JavaScript.
- `theme.js` — переключатель светлой и тёмной темы.

## Порядок действий

1. Выбери slug: строчные латинские буквы, цифры и дефисы. Например: `qwen-vs-llama`.
2. Скопируй `_template/index.html` в `<slug>/index.html`.
3. Заполни каркас:
   - в `<body data-page="">` впиши slug;
   - заполни `<title>`, `meta name="description"` и OG-теги;
   - внутри `.article-body` создай содержимое статьи. Классы и структуру бери из `beam-vs-deepseek/index.html`: тег, `h1`, интро, текст, при необходимости `specs`, график, таблицу, источники и `callout`.
4. Добавь объект в `pages.json` в конец массива:

   ```json
   {
     "slug": "qwen-vs-llama",
     "title": "Qwen vs Llama",
     "meta": "Benchmarks · Oct 2026"
   }
   ```

   Не забудь запятую после предыдущего объекта. В `pages.json` нужны двойные кавычки; если в заголовке есть двойная кавычка, экранируй её как `\"`.

5. Добавь строку в список `Pages` на `index.html` после последней строки:

   ```html
   <a class="page-row" href="./qwen-vs-llama/">
     <span class="page-num">02</span>
     <span><span class="page-title">Qwen vs Llama</span><span class="page-kind">Benchmarks · Oct 2026</span></span>
     <span class="page-desc">Одно предложение о том, что на странице.</span>
     <span class="page-arrow" aria-hidden="true">→</span>
   </a>
   ```

   `page-num` — номер статьи в списке (01, 02, ...), а не номер в меню. В меню Home идёт первым, поэтому у первой статьи там номер 02. Не добавляй `id="pages-title"` в строку: этот id уже стоит на заголовке секции.

6. Проверь страницу локально:

   ```powershell
   python -m http.server 8765 --bind 127.0.0.1
   ```

   Открой `http://127.0.0.1:8765/` и `http://127.0.0.1:8765/<slug>/`. Останови сервер через `Ctrl+C`.

7. Не коммить и не пушь без разрешения владельца репозитория.

## Готовый промпт для ChatGPT

Скопируй этот текст в ChatGPT с телефона и добавь в конце тему, текст поста и ссылки на источники. Если у ChatGPT нет доступа к репозиторию, приложи ему `_template/index.html`, `pages.json`, `index.html` и `beam-vs-deepseek/index.html`.

```text
Ты помогаешь вести статический сайт Dekrov Insights (GitHub Pages, репозиторий DekrovDev/dekrov-insights).

Контекст:
- Сайт без сборки и без базы данных. Страницы — обычные HTML-файлы.
- _template/index.html — пустой каркас страницы: шапка, меню, футер и пустой .article-body. Текста и примеров внутри нет.
- Образец готовой статьи со всеми классами: beam-vs-deepseek/index.html.
- Левое меню на всех страницах строится из pages.json с помощью site.js. Сайдбар в существующих статьях править не нужно.
- Список Pages на главной странице статический, его нужно дополнять вручную.
- Стиль: монохромный, Arial + Consolas, тонкие линии, без карточек и теней. Не меняй оформление без необходимости.
- Все пути относительные, сайт работает под /dekrov-insights/.

Задача: создать новую страницу.

1. Прочитай _template/index.html, pages.json, index.html и beam-vs-deepseek/index.html.
2. Придумай короткий slug на латинице и создай <slug>/index.html из пустого шаблона.
3. Заполни каркас: в <body data-page=""> впиши slug; заполни <title>, meta description и OG-теги. Заголовок в <title> и в pages.json должен быть без HTML-переносов; в <h1> можно использовать <br>.
4. Внутри .article-body создай содержание сам: тег, h1, вводный абзац, текст. При необходимости добавь specs, график, таблицу, источники и callout. Классы и разметку бери из beam-vs-deepseek/index.html. Не оставляй пустых блоков, примеров и плейсхолдеров. В графике копируй разметку из образца: значение --pct задаётся как 80.1%.
5. Добавь объект в JSON-массив pages.json (ключи в двойных кавычках): slug, короткий title для меню и meta (тип материала + месяц/год).
6. Добавь строку в список Pages на index.html после последней строки. Номер page-num — следующий по порядку статей (01, 02, ...). Не добавляй id="pages-title" в строку: этот id уже стоит на заголовке секции.
7. Проверь, что все ссылки относительные, тема и навигация работают, а на странице нет выдуманных цифр.
8. Для каждой цифры/бенчмарка укажи источник и дату оценки. Если данных нет — не добавляй график и таблицу, а напиши текстом.
9. Не коммить и не пушь изменения без отдельного разрешения.

В конце перечисли изменённые файлы и коротко напиши, что проверить.

Материал для страницы:
<вставь сюда тему, текст поста и ссылки>
```

## Важно

- Шаблон лежит в папке `_template`. GitHub Pages с Jekyll не публикует папки, начинающиеся с `_`, поэтому сам шаблон не попадёт в сайт.
- Если позже понадобится полностью автоматический список статей на главной, это отдельная задача: сейчас главная остаётся статической ради SEO и работы без JavaScript.
- `pages.json` подгружается без кэша, поэтому новая запись в меню появляется после обычного обновления страницы.
